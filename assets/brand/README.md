# Bench2Evidence brand assets

The Bench2Evidence mark is for the series as a whole, so it can carry over to future workshops and bridges. Event names, dates, and host-conference branding go in separate event lockups, never in the mark itself.

## The mark

Two rising bars step up into a bridge span that lands on a solid pier. Read left to right, it says "benchmarks to evidence".

- Geometry: one path on a 64 × 64 grid, in `mark.svg`. Don't redraw, round, outline, or add effects to it.
- Minimum size: 16 px (favicon). Below 24 px, use the mark alone, without the name.
- Clear space: keep at least the width of one bar (10/64 of the mark's width) free on every side.
- Colour: one colour only. Use ink `#16202c` on light backgrounds and white `#ffffff` on dark ones. Don't fill parts of it in different colours.

## Files

| File | Use |
| --- | --- |
| `mark.svg` / `mark-white.svg` | Mark only, as vectors. Use these for print, slides, and anywhere the logo needs to scale. |
| `mark-512.png` | Mark only, transparent PNG, for tools that don't accept SVG. |
| `lockup-dark.png` / `lockup-light.png` | Series lockup (mark + "Bench2Evidence"), transparent, 3× resolution. Use this for future events. |
| `lockup-aaai27-dark.png` / `lockup-aaai27-light.png` | Event lockup for the AAAI-27 Bridge Program only. |
| `apple-touch-icon.png`, `../../favicon.svg` | Site icons. |
| `og-image.png` | Social preview card for the AAAI-27 Bridge site. |

For a future event, copy the series lockup and add the event line under the name in Public Sans 500, about 40% of the name's size, in grey (`#5d6875` on light, `#d0d6de` on dark).

## Type and colour

- Name and UI text: Public Sans (Google Fonts), weight 700 for the name.
- Headings on the site: STIX Two Text.
- Ink `#16202c`, link blue `#1d4f91`, accent gold `#e0a526`. Use gold for accents only, never for text on white.

## Host-conference marks

Host-conference logos belong to their owners. The official AAAI logos (`../logos/aaai-color.svg`, `../logos/aaai-white.svg`, from https://aaai.org/about-aaai/aaai-logos/) are offered for AAAI workshop and symposium websites; use them unaltered, never recoloured. Show them next to the Bench2Evidence lockup, separated by space or a rule, and never merge them into it.

## Clearance

The mark was drawn for this project and isn't based on an existing logo. A web search found no other use of the name "Bench2Evidence" and no matching bridge-and-bars mark, but that is not a trademark clearance. Run a formal check before registering the mark or using it commercially.
